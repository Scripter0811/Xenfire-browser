Deploy free on Render:
1. Make a GitHub repo and upload ALL the files in this zip (drag them in; they're all in one level).
2. render.com > New > Web Service > pick the repo.
3. Build Command: npm install     Start Command: npm start     Instance: Free
4. Open the link Render gives you.

Test on your computer: npm install, then npm start, then open http://localhost:8080
Free tier sleeps when idle, so the first load can take 30-60 seconds.
